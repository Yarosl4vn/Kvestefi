# Квестефи

Мобильное Android-приложение для подготовки к **ОГЭ, ЕГЭ и ВПР**: решаешь задачи в формате экзамена, держишь серию дней, берёшь реальные задания из открытого банка и повторяешь теорию по материалам из свободных источников.

- **Пакет:** `ru.readysquad.kvest`
- **Язык:** Kotlin, XML-layouts, Material 3
- **minSdk:** 24 · **targetSdk / compileSdk:** 34
- **Версия:** 1.8.0 (versionCode 11)
- **Сборка:** Gradle 8.2 · AGP 8.2.2 · Kotlin 1.9.22
- **Офлайн:** частично. 154 встроенных задания, генератор тренировки, теория, шпаргалки и статистика работают без интернета. Интернет нужен для **онлайн-банка реальных заданий**, библиотеки материалов и курсов Stepik.

## Данные

**SQLite** `kvest_marathon.db` (схема версии 8):

| Таблица | Назначение |
|---|---|
| `subjects` | 11 предметов |
| `tasks` | 154 задания: предмет, тема, тип экзамена, сложность, вопрос, 4 варианта, верный индекс, разбор |

| `answers` | ответы по задачам — для анализа слабых тем |
| `badges` | 13 бейджей и дата выдачи |

Варианты ответов перемешиваются при каждой выдаче, а поля читаются **по именам колонок**, а не по позиции — чтобы изменение схемы не сдвигало значения.

**Профиль** (имя, иконка, цель, палитра, серия дней, повторённые темы) — в `SharedPreferences`.

## Источники материалов

### Задания: онлайн-банк + встроенный банк + генератор

**Официального API с заданиями ОГЭ/ЕГЭ не существует.** Открытые банки ФИПИ (`ege.fipi.ru/bank/`, `oge.fipi.ru/bank/`) — веб-приложения без публичного интерфейса; в открытом доступе есть только сторонние парсеры ([fipi-mcp](https://github.com/MasterGiGiK/fipi-mcp), [fipi_parser.py](https://github.com/avikiqwww/stereometry-solver-bot/pull/2)).

Поэтому работают три режима:

1. **Онлайн-банк** — `Sdamgia` (`data/Sdamgia.kt`). Реальные задания открытого образовательного портала.
   Подключено 9 предметов: математика, русский язык, история, физика, химия, биология, география, информатика, английский.
   Обществознание и литература не подключены: в этих разделах портала есть только задания с развёрнутым ответом,
   блока с кратким ответом на странице нет. Покрытие по уровням проверено запросами к порталу:
   математика ОГЭ 12/16 и ЕГЭ 16/16, русский ОГЭ 7/16 (в ЕГЭ условия на 11-19 тысяч знаков — не для карточки),
   история и физика 16/16 на обоих уровнях, география 11/16 и 16/16, информатика 16/16 и 10/16,
   английский 16/16 и 9/16, биология 9/16 и 7/16, химия 6/16 на обоих уровнях.
   Если по выбранному уровню заданий нет, приложение само берёт второй уровень. Схема: каталог предмета даёт темы (`category_id`), страница темы — ссылки на задачи, страница задачи — условие, рисунок, ответ и разбор.
   - Задания **запрашиваются в момент решения и не сохраняются** — приложение не хранит чужой банк заданий у себя.
   - Варианты ответа: у реальных заданий ответ краткий, поэтому `Sdamgia.optionsFor` строит четыре варианта — верный плюс три правдоподобных. Для чисел соседние значения, сдвиг на порядок, удвоение; для слов и названий — ответы других заданий того же раздела.
   - Рисунки грузятся по ссылке (`ImageLoader`, `Http.getImage`) — с заголовком Referer, иначе банк отдаёт изображение только со своей страницы.
   - У каждого задания показывается ссылка на источник.
   - Блоки условия, ответа и разбора ищутся с учётом вложенности тегов. Обрезать по «следующему маркеру» нельзя: между условием и разбором на странице стоят аналоги, кодификатор и реклама, и в ответ попадал весь остаток страницы.
   - Текст чистится сканером, который пропускает `>` внутри значений атрибутов: иначе обрывки скриптов из `onclick` попадали в формулировку задания.
   - Из темы берётся не больше двух заданий, иначе квест собирался бы из одной темы.
2. **Встроенный банк** — 154 задания офлайн, работают без интернета.
3. **«Тренировка»** — задания строит `TaskGenerator` кодом: проценты, уравнения, площади, среднее арифметическое, F = m·g, v = S/t, A = P·t, масса через плотность, относительная молекулярная масса, перевод в двоичную систему, биты и байты, масштаб карты.

Порядок чтения страниц банка одинаковый во всех режимах: `Sdamgia.quest()` отдаёт задания с рисунком и разбором, `QuizActivity` спрашивает выбор из четырёх вариантов, `RealTasksActivity` — ввод краткого ответа в клетки, как в бланке ответов № 1.

Контент банка принадлежит порталу. Приложение забирает небольшой объём для учебных целей и у каждого задания показывает прямую ссылку на источник.

Свой источник подключается через интерфейс `TaskSource`:

```kotlin
interface TaskSource {
    val name: String
    val isOffline: Boolean
    fun load(subjectCode: String, limit: Int): List<Task>
}
```

### Библиотека: три свободных API без ключа

| Источник | Что берём | Запрос |
|---|---|---|
| Википедия | вступление в 3 предложения, обрезается по границе предложения | `ru.wikipedia.org/w/api.php?action=query&generator=search&prop=extracts&exsentences=3` |
| Викисловарь | только раздел «Значение» — короткое толкование | `ru.wiktionary.org/w/api.php?action=query&titles=…&prop=extracts&explaintext=1` |
| Wikimedia Commons | до 4 картинок по теме (для SVG сервис отдаёт PNG-миниатюру) | `commons.wikimedia.org/w/api.php?action=query&generator=search&gsrnamespace=6&prop=imageinfo` |

Тексты — лицензия CC BY-SA. DuckDuckGo Instant Answer не используется: на русские запросы он возвращает пустой ответ.

### Курсы: открытый каталог Stepik

| Источник | Что берём | Запрос |
|---|---|---|
| Stepik | название, описание, обложка, число записавшихся, ссылка на курс | `stepik.org/api/courses?search=…&page=1` |

Ключ не нужен. Курсы не скачиваются: пользователь открывает их на сайте Stepik. Разбор ответа — `data/Stepik.kt`, битые записи пропускаются.

## Что изменилось в 1.8.0

- **Уведомления.** В шапке главного экрана появился колокольчик с красной меткой: достижения, цель дня, серия под угрозой, слабые темы. Метка снимается после просмотра.
- **Достижения стали интерактивными.** Нажатие на бейдж открывает карточку: как его получить, открыт ли он и когда. Непросмотренные бейджи показываются цифрой на вкладке «Достижения».
- **История попыток ожила.** Попытку можно открыть и увидеть каждое задание: вопрос, свой ответ и верный ответ. Раньше хранился только результат.
- **Статистика по предмету.** Из попытки открывается разбор по предмету: число попыток, точность, динамика результата по датам и темы с низкой точностью.
- **Карточки главного экрана работают.** Уровень, цель на сегодня, серия дней и последний квест открывают подробности, а не молчат. Уровень считается общей формулой, из подробностей доступен личный топ по предметам.
- **Фотографии в библиотеке открываются на весь экран.**
- **Курсы Stepik грузятся надёжнее:** если по длинному запросу каталог пуст, запрос повторяется по первому слову, а пустой результат объясняется понятным текстом.
- **В «Квестах» видны все 11 предметов.** Если по предмету нет онлайн-заданий с кратким ответом (обществознание, литература), карточка предупреждает и открывает встроенный набор.
- Схема базы поднята до версии 8: в ответах сохраняются вопрос, ответ игрока и верный ответ. Обновление не стирает прогресс.

## Как запустить

**Вариант 1 — Android Studio**

1. Склонировать репозиторий: `git clone <адрес-репозитория>`
2. Открыть папку проекта в Android Studio.
3. Дождаться синхронизации Gradle.
4. Подключить телефон с отладкой по USB или запустить эмулятор (Android 7.0 и новее).
5. Нажать Run — приложение установится и откроется на экране приветствия.

**Вариант 2 — командная строка**

```
export JAVA_HOME=/path/to/jdk17        # Windows: set JAVA_HOME=C:\jdk17
export ANDROID_HOME=/path/to/sdk       # Windows: set ANDROID_HOME=C:\sdk
./gradlew assembleDebug                # Windows: gradlew.bat assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Готовый подписанный APK собирается командой `./gradlew assembleRelease`.
